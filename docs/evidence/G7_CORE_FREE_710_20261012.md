## 원본 무수정 증거

공식 tag에서 별도 추출한 `app`, `bootstrap`, `config`, `routes`, core JS/views, `modules`, `templates` 및 dependency manifest를
테스트 host와 `native_snapshot()`으로 비교했습니다. 자체 모듈, dependency 디렉터리, 생성 bootstrap cache는 제외합니다.

- 원본 파일: 9,292개
- 추가/변경/삭제: 0개
- canonical snapshot SHA-256: `284e9f9dc3dc0db6ecf712a763a73187af1ca6653e35f3ea5722913e92e23668`

자동 설치기도 동일한 전후 원본 해시 검사를 수행하고 원본을 복원/덮어쓰는 기능은 제거했습니다.
실제 사용자 ZIP 설치 전체를 실행한 증거와는 구분합니다.

단위 layout 검사는 source 구조의 변환 검증이며 렌더링된 브라우저 증거가 아닙니다.

## 구현한 변경

- 기존 patch capability, URL filter, 고정 FileUploader ID 의존성 제거
- 공식 layout filter와 stock save 이벤트 연결
- native 게시글 저장의 owner-scoped atomic attachment linking
- 기존 attachment URL 유지와 원본 권한 검사 재사용
- 업로드 off 시 원본 UI 복원 및 기존 미디어 전달 유지
- 매핑이 남아 있을 때 전체 모듈 제거 차단
- 모듈 전용 설치/rollback, 원본 수정 감지
